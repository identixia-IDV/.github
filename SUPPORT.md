# Get help with Identixia

For product selection, evaluation licenses, deployment questions, or integration support, email [contact@identixia.com](mailto:contact@identixia.com).

- [Documentation and integration guides](https://docs.identixia.com)
- [Choose a product](https://docs.identixia.com/guides/choose-a-product)
- [Interactive playground](https://playground.identixia.com/)
- [WhatsApp](https://wa.me/17018854218) · [Telegram](https://t.me/identixia)

For an evaluation, include your product, platform, intended workflow, and deployment environment. Send an application ID or machine code privately when requesting a license.

For a reproducible sample or documentation issue, open an issue in the affected product repository. Include the SDK version, operating system, expected behavior, actual behavior, and a minimal reproduction with redacted logs.

Do not post license keys, access tokens, customer data, face images, biometric templates, or identity documents in public issues. Use synthetic examples. Report potential security vulnerabilities privately as described in [SECURITY.md](https://github.com/identixia-IDV/.github/blob/main/SECURITY.md).
