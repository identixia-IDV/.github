**Identixia builds identity verification software for teams integrating digital onboarding, biometric authentication, and KYC workflows.** Combine face recognition, selfie liveness, ID document recognition, and document authenticity checks—or choose the SDK your application needs.

## <img src="https://api.iconify.design/lucide/workflow.svg?color=%230F9F95" width="26" height="26" alt="" /> Build your verification journey

**Capture a document → extract identity fields → check document authenticity → capture a selfie → check liveness → compare faces → review the result.**

Use the individual SDKs within your existing application, or explore the [Identixia IDV platform](https://docs.identixia.com/documentation/idv) to coordinate capture, sessions, and reviews. Your application determines the decision policy for your workflow.

### Can I run verification on my own infrastructure?

Yes. Identixia provides self-hosted server engines and an IDV platform, along with on-device mobile SDK integrations. See the selected product's deployment guide for its requirements.

### Do I need the full identity verification platform?

You can integrate individual face and document SDKs into an existing system. The IDV platform adds session management, capture flows, and review tools for a coordinated verification process.

### Where can I confirm document coverage and licensing?

Contact the team with the countries, document types, platforms, and capabilities you need. Confirm coverage and evaluate representative samples before deployment.
