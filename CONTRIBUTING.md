# Contributing to Identixia samples and documentation

We welcome clear bug reports, documentation corrections, and improvements to public integration samples.

1. Read the affected repository's setup guide and contribution instructions.
2. For a substantial change, open an issue describing the problem and proposed approach first.
3. Keep the change focused and explain how to reproduce or verify the improvement.
4. Run the relevant checks described by the affected repository and record the results in your pull request.

Use synthetic test data. Never commit credentials, license files, proprietary SDK binaries, biometric templates, or customer identity documents. Do not change product claims, supported platforms, or licensing statements without supporting evidence.

Public samples and commercial SDK runtimes can have different licensing terms. Follow the license of the repository you are contributing to and contribute only material you have the right to share.

For licensing and integration questions, see [support](https://github.com/identixia-IDV/.github/blob/main/SUPPORT.md). For vulnerabilities, follow the [security policy](https://github.com/identixia-IDV/.github/blob/main/SECURITY.md).
